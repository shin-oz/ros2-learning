- 仮想関数
スーパークラスの処理をサブクラスにゆだねる
処理自体は同じ名前で呼び出すが、中身が異なる
例：鳥が鳴く　処理について、鳴く関数は同じだが、カラスが鳴くのとニワトリが鳴くので中身が異なる

```cpp
class CBird {
  public:
    // 仮想関数
    virtual void sing() {cout << "鳥が鳴きます" << endl;}
    // 仮想関数ではない
    void fly() {cout << "鳥が飛びます" << endl;}
}
```

- 完全仮想関数
メソッドは存在するが、実装がないクラス。
このクラスを継承したサブクラスで実装する。
```cpp
virtual void sing() = 0; // 詳細な処理はサブクラス側で実施　
```

- 仮想デストラクタ
virtualをつけたメソッドは仮想関数になるため、スーパークラスからメンバ関数が呼ばれた場合は子クラスの処理が実行される。virtualがないとサブクラスのデストラクタが実行されない

- インターフェース
完全仮想関数のみからなるクラスのこと
※オブジェクト思考言語の重要な概念で、クラスを分ける際に、インターフェースを用いる。アクセス制限をつけるイメージ
