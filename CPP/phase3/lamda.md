## ラムダ式
名前をつけずにその場で関数を定義する

キャプチャ
ラムダ式の外側で定義されあ変数を、ラムダ式の中で使えるようにする仕組み
ラムダ式に最初にある[]

[-]　外部変数の値をキャプチャし、値コピーのため外部変数変更しても影響受けない
[&]　値キャプチャし、コピーはしないので値変更すると影響受ける
[変数名]　変数名　だけ値キャプチャし、値コピーのため外部変数変更しても影響受けない
[変数名&] 変数名を参照するため値キャプチャし、外部変数を変更すると影響受ける

this　現在操作しているオブジェクト自信を示すポインタ

```cpp
auto plus = [](int a, int b) { return a + b; };
int result = plus(2, 3); // result == 5
```
