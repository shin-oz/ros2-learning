## ラムダ式
名前をつけずにその場で関数を定義する

キャプチャ
ラムダ式の外側で定義された変数を、ラムダ式の中で使えるようにする仕組み
ラムダ式に最初にある[]

[=]　外部変数のすべて、値でコピーして、キャプチャする
[&]　参照キャプチャ。外側の変数を変えるとラムダからも変わって見え、ラムダの中から変えると外側の変数も変わる
[変数名]　変数名　だけ値キャプチャし、値コピーのため外部変数変更しても影響受けない
[&変数名] 変数名を参照するため値キャプチャし、外部変数を変更すると影響受ける

this　現在操作しているオブジェクト自身を示すポインタ
[this] ラムダからメンバ関数やメンバ変数を使えるようになる

```cpp
auto plus = [](int a, int b) { return a + b; };
int result = plus(2, 3); // result == 5
```
